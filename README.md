# SocioWise

SocioWise is a social media application designed to facilitate user interaction and content sharing. Built with JavaScript and HTML, SocioWise aims to provide a seamless social networking experience with robust features and a user-friendly interface.

## Features

- User authentication and profile management
- Post creation, editing, and deletion
- Like and comment functionalities
- Real-time updates and notifications
- Responsive design for various devices

## Technologies Used

- JavaScript
- HTML
- CSS
- Node.js
- Express.js
- MongoDB
- WebSockets

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/jasmeets7/SocioWise.git
    ```

2. Navigate to the project directory:
    ```sh
    cd SocioWise
    ```

3. Install dependencies:
    ```sh
    npm install
    ```

4. Set up environment variables:
    Create a `.env` file in the root directory and add your MongoDB URI and any other required environment variables.

5. Run the application:
    ```sh
    npm start
    ```

6. Open your browser and navigate to `http://localhost:3000/`.

## Usage

Once the application is running, you can sign up, create a profile, and start interacting with other users by posting updates, liking posts, and leaving comments.
